# Step5：動画を1本ずつ進める構成

Step5は「説明 → 1本目〜10本目 → クリア」の順に進みます。動画ごとの画面には、専用素材、専用見本動画、提出チェック、前後の移動ボタンがあります。提出チェックを付けるまでは次の動画に進めません。10本目を提出し、全10本のチェックがそろうとクリア画面へ移動します。

利用者から指定された次の順番で10本分を登録しています。見本は元のMOVから映像・音声を再圧縮せずMP4に入れ替え、元MOVも保持しています。ZIPにはテーマごとの画像だけを含め、見本動画とは分けて表示します。

以前の1本目「癒し」は承認された10本目に移し、既存ファイルを削除・上書きせず使用します。ZIP内のフォルダー名も10本目に合わせて新しく用意しています。元素材の記録は `step5-video1-assets.json`、今回の9テーマの記録は `step5-collection-assets.json` にあります。提出チェックは従来どおり動画番号ごとに保持し、今回の並べ替えでチェックの移動や初期化は行いません。

## 素材を登録する場所

`app/step-five-materials.ts` の `PRACTICE_VIDEOS` が10本分の設定です。`id` は1〜10で、配列の順番もこの順に維持します。

- `editingMaterials`：動画・画像・ZIPなどのダウンロード情報の配列。`label`（表示名）、`href`（実際のファイルのURL）、必要なら `downloadName`（保存時の名前）を設定します。
- `title`：教材に表示するテーマ名。
- `referenceVideo`：見本動画がない間は `null`。提供後に `src`（実際の動画URL）、必要なら `mimeType` と `downloadName` を設定します。

提供された実ファイルを `public/` に保存してから、そのファイルのURLを各動画の設定に登録してください。素材を共用する指定がない限り、動画ごとの設定を使います。今回は素材のアップロード管理画面は追加していません。

## 保存と以前のデータ

提出チェックのキー `step5-video-1-submitted`〜`step5-video-10-submitted` は変更していません。現在見ている動画は既存の `form_values` 内の `step5VideoIndex`（0〜9）に保存します。現在の構成を示す `step5Layout: sequential-v1` も同じ場所に保存します。

以前の5画面構成のページ位置は、Step5を開くときだけ新構成へ読み替えます。未提出の最初の動画から続けられます。過去に飛び飛びにチェックした動画も、チェック自体は削除しません。新構成では、途中に未提出の動画があればその動画までに進む範囲を制限します。前の動画へはいつでも戻れます。

DBの列やテーブル、ログイン、管理者API、Google分析シート連携は変更していません。DB移行は不要です。
