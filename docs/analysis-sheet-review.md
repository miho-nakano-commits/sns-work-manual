# Google分析シートとの対応（2026年10月27日確認）

対象は既存Apps Scriptが参照するテンプレート「雛形【SNS分析用】シャマル」です。閲覧のみ行い、シートの内容・列・数式・権限・Apps Script・本番環境変数は変更していません。

- [リール分析](https://docs.google.com/spreadsheets/d/1NfHeZFICoyZkaCZAvLTOme_ehrMebp4vzH_DNnTCVHc/edit#gid=776298183)
- [共通点探し](https://docs.google.com/spreadsheets/d/1NfHeZFICoyZkaCZAvLTOme_ehrMebp4vzH_DNnTCVHc/edit#gid=1975347497)

## 既存の見出し

「リール分析」B〜I列：※投稿URL、※再生数、※FW数、BGMの有無、※リールの内容、冒頭3秒の内容、※コメントが来ている内容、活かせるポイント。※は必須、それ以外は分かる範囲で記入する案内です。Step2もこの項目に合わせました。

「共通点探し」B〜I列：自動入力されます（URL）、人は映っている？、動画に文字は入っている？、動画の最初に目立つものがありますか？、動画の長さ（大体でOK）、映像が切り替わる？、話している声は入っている？、どんな内容の動画？。

## Step3の6項目との対応

| 教材で分析する内容 | 利用できる既存欄 | 追加検討が必要な点 |
| --- | --- | --- |
| 最初の3秒で何を見せているか | リール分析「冒頭3秒の内容」 | 追加不要 |
| 動画の長さ | 共通点探し「動画の長さ」 | 追加不要 |
| テロップの特徴 | 共通点探し「動画に文字は入っている？」 | 大きさ・色・表示タイミングなどを記録する専用欄がない |
| BGMや効果音の使い方 | リール分析「BGMの有無」 | 効果音や音の使い方を記録する専用欄がない。「話している声」の欄では代用できない |
| 映像の切り替え方 | 共通点探し「映像が切り替わる？」 | まず既存の選択肢で記録。詳しい記録が必要なら記述欄を別途検討 |
| 最後まで見たくなる工夫 | 関連する気づきは「活かせるポイント」に記録できる | 専用欄がない |

専用欄の追加候補は「テロップの詳しい特徴」「BGM・効果音の使い方」「最後まで見たくなる工夫」の3点です。今回、列の追加や連携仕様の変更はしていません。教材には、既存欄を使うことと、欄がない内容の記録方法を職員へ確認する案内を入れています。

テンプレートの「ルール」にはStep1の旧来の3条件が残っています。調査日基準の直近1か月の条件と、50件の作業量に合わせた案内の見直しは、シート管理者の確認事項です。既存の利用者別シートへも変更を反映するか、別途決める必要があります。

## 連携の検証範囲

テンプレートID、保存先、Apps Script、作成APIは変更していません。確認用SQLiteとテスト応答で、ログイン利用者名・秘密値を送る形式と、既存シートURLを受け取る処理を検証しました。本番Apps Scriptへの送信やGoogle Drive上のファイル作成はしていません。本番設定と権限の確認を含む、実シートの作成テストは別途必要です。
